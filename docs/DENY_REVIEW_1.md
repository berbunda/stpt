# Проверка лицензий STPT

28 ноября 2026 года. Первоначальный разбор выполнен на локальной версии 0.6.0-1. Полная проверка cargo-deny также повторена на отдельной копии публикуемых файлов версии 0.5.0-2 с её собственным `Cargo.lock`: результат совпал с таблицей ниже. В локальном журнале от 27 ноября (`DENY_REVIEW.md`) зафиксировано 139 ошибок `rejected`. Причина указана в первой строке диагностики: `cargo-deny` не нашёл конфигурацию и применил пустой список разрешённых лицензий. Инструмент корректно отклонил все 139 пакетов, включая сам STPT. По этому результату нельзя заключить, что зависимости конфликтуют с GPLv3. [Правила проверки cargo-deny](https://embarkstudios.github.io/cargo-deny/checks/licenses/cfg.html#allow)

## Какие условия применимы

Код под MIT, ISC, BSD-2-Clause, BSD-3-Clause и Apache-2.0 можно включать в программу, распространяемую под GPLv3. При распространении сохраняются условия выбранных лицензий компонентов, в том числе применимые уведомления об авторских правах, тексты лицензий и отказов от гарантий. Для Apache-2.0 также учитываются применимые уведомления из NOTICE, если компонент его содержит. Для бинарного выпуска STPT отдельно действуют требования GPLv3 к предоставлению соответствующего исходного кода. [Совместимость лицензий по GNU](https://www.gnu.org/licenses/license-compatibility.en.html) · [Apache-2.0, §4](https://www.apache.org/licenses/LICENSE-2.0#redistribution) · [GPLv3, §6](https://www.gnu.org/licenses/gpl-3.0.html#section6)

| Пакет из проверенного графа | Как читать выражение в отчёте |
|---|---|
| `zerocopy 0.8.66` | `BSD-2-Clause OR Apache-2.0 OR MIT` допускает выбор одной лицензии. Достаточно MIT. |
| `subtle 2.6.1` | Указана только `BSD-3-Clause`. Её условия нужно учесть. |
| `aws-lc-sys 0.47.0` | Выражение содержит обязательные `ISC`, `Apache-2.0`, `MIT` и `BSD-3-Clause`. Эти же лицензии удовлетворяют всем группам с `OR` внутри выражения. |
| `unicode-ident 1.0.27` | В `(MIT OR Apache-2.0) AND Unicode-3.0` выбор MIT или Apache-2.0 сохраняет обязательное условие Unicode-3.0 для данных Unicode. [Лицензия Unicode](https://www.unicode.org/license.txt) |
| `r-efi 6.0.0` | В `MIT OR Apache-2.0 OR LGPL-2.1-or-later` можно выбрать MIT. Этот пакет не требует включать LGPL в общую политику. |

## Политика проекта и результат проверки

Правообладатель выбрал `GPL-3.0-only` для STPT. Эта лицензия указана в разделе `[package]` манифеста. Конфигурация разрешает Apache-2.0, BSD-3-Clause, ISC, MIT и Unicode-3.0 для зависимостей. Разрешение на GPL-3.0-only ограничено пакетом `stpt`. [Cargo.toml](../Cargo.toml) · [deny.toml](../deny.toml)

28 ноября 2026 года на Windows из каталога программы выполнен полный `cargo deny check` с cargo-deny 0.22.2. Код выхода — 0. Повторный запуск с текущим файлом блокировки и локальным кэшем показал следующую статистику.

```powershell
cargo deny --locked --offline check --show-stats
```

## Дубликаты зависимостей

| Пакет | Откуда берутся версии | Решение |
|---|---|---|
| `nix` | STPT запрашивал `^0.32.0`, а Linux-библиотека `fuser 0.19.0` требует `^0.31.0`. | Прямая зависимость STPT теперь требует `^0.31.4` с прежним набором возможностей. Cargo использует один `nix 0.31.4` для обоих потребителей. В этот патч перенесены исправления `recvfrom` и обработки ошибок `posix_spawn`. |
| `getrandom` | `ring 0.17.14` требует `^0.2.10`; `quinn-proto 0.11.19`, `rand 0.10.4` и `jobserver 0.1.35` используют ветку 0.4. | Граф для всех платформ содержит 0.2.17 и 0.4.3. В деревьях Windows x64 и Linux x64 присутствует только версия 0.4.3. |
| `windows-sys` | `ring 0.17.14` требует `^0.52` на Windows; STPT, Tokio и Mio требуют `^0.61`. | В полном графе разрешены 0.52.0 и 0.61.2. В дереве сборки Windows x64 присутствует только 0.61.2. |
| `syn` | `num_enum_derive 0.7.6` (через `fuser`), `tracing-attributes 0.1.31` и `zerocopy-derive 0.8.66` требуют ветку 2. Макросы `clap_derive 4.6.9`, `serde_derive 1.0.229` и `tokio-macros 2.7.2` требуют ветку 3. | Обе версии (2.0.119 и 3.0.10) нужны при сборке. Одной версией нельзя удовлетворить ограничения этих макросов. |

STPT включает у Quinn `rustls-aws-lc-rs`. В манифесте `quinn-proto` для цели `wasm32-unknown-unknown` присутствует отдельная зависимость от `ring`. Проверка всех платформ поэтому видит `ring` и его зависимости. Фильтровать платформы или подавлять предупреждения в `deny.toml` для получения этих результатов не требуется.

Ограничения проверены через `cargo metadata --locked --offline --format-version 1`. На 28 ноября 2026 года `cargo update --dry-run` предложил 0 обновлений в допустимых диапазонах. Повторить разбор включения `ring` и сравнить две основные платформы можно из каталога программы:

```powershell
cargo tree --locked --target all -e features -i ring
cargo tree --locked --target x86_64-pc-windows-msvc --duplicates
cargo tree --locked --target x86_64-unknown-linux-gnu --duplicates
```

После объединения `nix` команда `cargo check --locked --offline --all-targets` успешно проверила программу и тестовые цели для Windows x64. Та же проверка с `--target x86_64-unknown-linux-gnu` прошла на Windows с локальным кросс-компилятором C для нативных зависимостей. Тесты на исполнение в Linux в эту проверку не входили.
